# Public examples

- Examples must be safe for the same audience as public documentation. Do not
  include hidden verifier code, oracle answers for evaluation tasks, private
  lineage, selector seeds or inaccessible paths.
- Trajectories explain observable tool use and failures; they are not the unique
  oracle and must not be mounted into evaluation views unless the task contract
  explicitly makes them public.
- Keep examples small, deterministic and linked to the exact interface version
  they demonstrate.
